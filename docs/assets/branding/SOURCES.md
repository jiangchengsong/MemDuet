# Brand asset sources

- `xjtu-red.png`: Xi’an Jiaotong University visual identity website, standard red logo lockup. Original file: https://vi.xjtu.edu.cn/images/a4-2xbred.png ; usage reference: https://vi.xjtu.edu.cn/jcbf/xhgf.htm .
- `iair-cai-white.png`: Institute of Artificial Intelligence and Robotics / College of Artificial Intelligence joint masthead, downloaded unchanged from https://iair.xjtu.edu.cn/images/8899.png . The page uses CSS viewports to show each existing mark separately in a single colour.
- `huggingface.svg`: Official Hugging Face monochrome logo from https://huggingface.co/datasets/huggingface/brand-assets/resolve/main/hf-logo-monochrome.svg ; reference: https://huggingface.co/brand .

- `hai.png`: Original HAI / Est. 2022 logo embedded in the State Key Laboratory presentation template supplied by the project author; extracted unchanged from `ppt/media/image1.png`. A CSS viewport displays the HAI / Est. 2022 mark; the full laboratory name is retained in the author affiliation and accessible label.

- `github.svg`: GitHub mark from Primer Octicons, https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg . The Octicons MIT license is retained in `OCTICONS-LICENSE.txt`.

Institutional and product marks belong to their respective owners. They identify the institutions and resource destinations on this project page; the repository’s code license does not relicense these marks.
